# System Settings (`org.atlas.settings`)

Interactive system settings and hardware telemetry application for **ATLAS OS**.

## Overview
- **Master Audio Volume:** 0% (Mute) to 100% with real-time test tone feedback and SD_MODE sleep gating.
- **UI Sound FX:** Toggle interface navigation beeps ON / OFF.
- **Display Themes:** Switch between Cyberpunk Dark, Monochrome High-Contrast, and Amber CRT Retro palettes.
- **SD Card & Packaging:** View FAT32 health and trigger catalogue re-scanning.
- **Live Diagnostics:** Monitor silicon model, dual-core CPU telemetry, free internal SRAM, free Octal PSRAM, and OTA rollback state.
- **NVS Flash Persistence:** Settings automatically persist across system reboots.

## Controls
- **Joystick UP / DOWN:** Select settings row.
- **Joystick LEFT / RIGHT or Button A:** Adjust selected setting.
- **Button B (SW2) / Button C (Menu):** Save configuration to NVS and exit to Home Launcher.
