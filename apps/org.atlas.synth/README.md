# Chiptune Synthesizer (`org.atlas.synth`)

Live 8-bit sound synthesizer for **ATLAS OS**.

## Overview
- Generates real-time audio waveforms piped directly to the MAX98357A I2S DAC.
- Real-time oscilloscope visualizer on the 320x240 LCD display.
- Dynamic pitch modulation with ADC1 joystick.

## Controls
- **Joystick X:** Modulate frequency (100 Hz to 2000 Hz).
- **Button A (SW1):** Hold to generate sound tone.
- **Button B (SW2):** Exit to Home Launcher.
